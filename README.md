# App chat realtime

This is a real-time chat application built with a modern tech stack including React, Node.js, Express, MongoDB, and Socket.io. The app allows users to sign up, sign in, and engage in real-time messaging.

## Technologies Used

- Backend:
  - Node.js
  - Express
  - MongoDB with Mongoose
  - Socket.io
- Frontend:
  - React
  - Zustand
  - Axios
  - Socket.io-client

## Sumary

Đây là một ứng dụn với mục đích học tập nên code sẽ ko hoàn hão
Nhưng qua project này học được rất nhiều từ authentication, authorization, quản lý trạng thái với Zustand, kết nối realtime với Socket.io, và cách tổ chức project một cách rõ ràng.
